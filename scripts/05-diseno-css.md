# Guion detallado — Lección 5: Centrado, espacios y bordes

**Duración:** 11 minutos · **Público:** 12 a 17 años · **Editor:** CodePen (https://codepen.io/pen)

> **Nota de producción:** Las duraciones incluyen lectura pausada, navegación, escritura real del código y silencios de práctica. Ensayar con cronómetro; no acelerar la voz para completar el tiempo.

## Diapositiva 1 · 00:00–02:00 — Introducción

**Narración sugerida:** Nuestra página tiene colores, pero podemos organizarla mejor. Imagina un texto pegado al borde de una caja: sería incómodo de leer. Hoy aprenderemos a crear una tarjeta con espacio suficiente y bordes redondeados.

**En pantalla:** Mostrar la primera diapositiva y un ejemplo visual. Formular una pregunta y dejar 10–15 segundos para pensar.

## Diapositiva 2 · 02:00–04:30 — Concepto nuevo

**Narración sugerida:** En el modelo de caja, padding es espacio interior, border es el contorno y margin es espacio exterior. max-width limita el ancho; margin con auto puede centrar horizontalmente un bloque de ancho limitado. border-radius suaviza las esquinas.

**En pantalla:** Mostrar la segunda diapositiva. Señalar cada etiqueta, propiedad o parte del esquema. Repetir la idea principal con un ejemplo diferente.

## Diapositiva 3 · 04:30–08:00 — Demostración en CodePen

**Narración sugerida:** En CodePen, agrupa el contenido dentro de main con class tarjeta. En CSS selecciona .tarjeta y escribe background-color, max-width, margin, padding, border y border-radius. Cambia padding de 12px a 24px para comparar. Prueba text-align center y comprueba el efecto.

**Acciones:** Abrir https://codepen.io/pen/, copiar el código de `starter-files/05-diseno-css/html.txt` y `css.txt`, escribir las modificaciones paso a paso y contrastar con `completed-examples/05-diseno-css/`. Hacer zoom al editor y explicar cada cambio antes de escribirlo.

## Diapositiva 4 · 08:00–10:00 — Práctica y cierre

**Narración sugerida:** Reto: cambia el borde, el redondeo y el espacio interno. Si el diseño no cambia, revisa que el nombre de la clase coincida entre HTML y CSS y que en CSS el selector de clase empiece con punto. ¡Tu página parece ahora una tarjeta de perfil!

**En pantalla:** Mostrar el reto, guardar silencio durante 30–45 segundos o indicar al estudiante que pause, comprobar la solución y despedirse enlazando con la siguiente lección.
